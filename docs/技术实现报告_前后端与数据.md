## 二、后端架构（Python FastAPI）

### 2.1 分层结构

```
backend/app/
├── main.py              # FastAPI 入口：REST接口 + SSE流式 + 生命周期管理
├── config.py            # 配置（LLM Key/目录）
├── agent/
│   ├── core.py          # Agent核心：LLM Function Calling循环 + 规则引擎降级（双模式）
│   └── tools.py         # 7个工具Schema（OpenAI协议）+ 统一执行分发
├── knowledge/
│   ├── rag.py           # RAG引擎：混合检索（MiniLM语义+bigram关键词，RRF融合）
│   └── cases.py         # 案例相似度检索（bigram+触发路径加权）
├── models/
│   ├── input_output.py  # 双模型引擎：Leontief需求侧 + Ghosh供给侧 + 三阶段预判
│   ├── association.py   # 灰色关联、时差相关、投入产出加权网络
│   └── risk.py          # 风险评分模型（四指标加权，行业/系统性两级）
└── services/
    ├── store.py         # SQLite持久化（报告/上传，WAL模式，重启恢复）
    ├── report.py        # 完整/摘要 Markdown 与 PDF 报告生成
    ├── research.py      # 产业关联研究接口
    ├── v2.py            # 知识、机制、仿真、策略与案例接口
    └── upload.py         # CSV/Excel解析 + 风险指标识别
```

### 2.2 核心接口

| 接口 | 功能 |
|---|---|
| `POST /api/chat` | 同步问答（返回结构化报告 JSON） |
| `GET /api/chat/stream` | **SSE 流式**：实时推送工具调用轨迹（"→执行中/✓完成"逐条显示） |
| `POST /api/upload` | 数据上传（自动统计画像 + 指标识别 + 风险评分） |
| `GET /api/uploads` `/api/upload/{fid}` `/raw` | 上传文件列表/详情/原文查看 |
| `GET /api/dashboard` | 仪表盘聚合数据（评分/图谱/月度序列/三阶段） |
| `GET /api/industry/{name}` | 节点画像（消耗结构/乘数/负债率/最新月度） |
| `GET/DELETE /api/report(s)` | 报告查询与删除（三层同步：内存+SQLite+MD文件） |
| `GET /api/report/{rid}/pdf` | 完整报告或精简摘要 PDF 直下载 |
| `GET /api/v2/overview` `/cases` `/strategies` | V2知识、案例与分主体策略 |
| `POST /api/v2/simulate` | 0-24个月机制化压力曲线与静态行业影响 |

### 2.3 Agent 工具层（7 个）

| 工具 | 引擎 | 说明 |
|---|---|---|
| `search_knowledge_base` | 混合检索 | 回答金融问题前强制调用 |
| `analyze_industry_chain_impact` | Leontief | 需求侧冲击 → 影响矩阵（直接+间接效应分解、乘数） |
| `analyze_supply_shock` | **Ghosh** | 供给侧冲击 → 初始投入收缩沿产业关联网络传导（数量型供给收缩类问题自动路由） |
| `compute_risk_score` | 加权模型 | 行业风险评分 0-100 |
| `retrieve_similar_cases` | 案例库 | 结构化案例与带证据状态的研究线索检索 |
| `analyze_uploaded_data` | pandas | 用户上传数据融合 |
| `get_dashboard_data` | — | 仪表盘数据 |

### 2.4 可靠性设计（比赛现场不翻车的保证）

1. **双模式**：LLM 不可用/输出解析失败 → 自动降级规则引擎，全功能保持
2. **数字与文字分离**：所有测算数值由模型引擎确定性计算，LLM 只负责解读（杜绝幻觉数字）
3. **字段兜底**：`_enrich_report` 确保影响矩阵/评分明细/三阶段/案例在两种模式下结构一致
4. **检索三级降级**：MiniLM 语义 → bigram 词袋 → 纯关键词（无网/无模型均可检索）
5. **持久化**：SQLite 落库，服务重启零丢失

| 脚本 | 用途 |
|---|---|
| `extract_national_io_2023.py` | 全国211部门投入产出表 → 13部门 A 矩阵并记录文件指纹 |
| `extract_multiyear.py` | 2012/2017/2023 三年份提取与对比 |
| `import_documents.py` | PDF/DOCX/XLS 批量转知识库文档 |
| `import_real_data.py` | 真实负债率/月度序列入库 |
| `extract_cases.py` / `upgrade_case_impacts.py` | 案例结构化与量化升级 |
| `smoke_test.py` 等验证脚本 | 各功能回归测试 |

## 三、前端架构（React + Vite + Tailwind + ECharts）

### 3.1 页面结构

```
frontend/src/
├── App.jsx                 # 七大核心模块侧边栏导航
├── api.js                  # Axios封装 + 风险配色映射
├── components/
│   ├── Chart.jsx           # ECharts通用封装（StrictMode安全）
│   └── ForceGraph.jsx      # 力导向产业链图谱（防抖三保险+自适应填充+节点点击）
└── pages/
    ├── Home.jsx            # 智能问答：SSE流式轨迹 + 结构化报告卡 + 对话删除
    ├── Knowledge.jsx       # 传导知识库：模型、理论、检索与案例
    ├── Research.jsx        # 静态传导：灰色关联、时差、投入产出网络
    ├── Mechanism.jsx       # 五类机制、时滞、指标与理论依据
    ├── Simulation.jsx      # 0-24个月交互式动态传导仿真
    ├── Strategy.jsx        # 八类主体受控策略与溯源
    ├── Dashboard.jsx       # 风险仪表盘：9个可视化模块
    ├── Upload.jsx          # 数据上传：拖拽+统计画像+文件列表管理
    └── Reports.jsx         # 专业报告：完整/摘要切换、MD/PDF下载与删除
```

### 3.2 Dashboard 可视化清单

| 模块 | 图表类型 | 数据源 |
|---|---|---|
| 综合风险评分 | 仪表盘（Gauge） | 风险评分模型 |
| 行业影响 | 条形图（标注供给侧/需求侧模型徽章） | 双模型引擎 |
| 产业链传导图谱 | 力导向图（55+连线=消耗系数≥0.03，节点大小=冲击度，点击弹画像卡） | A 矩阵 |
| 历史对比 | 折线图（地产投资 vs GDP，2015-2024） | macro_history |
| 案例对标 | 列表卡（含量化影响） | 案例库 |
| 建议关注指标 | 标签墙 | Agent 输出 |
| **传导验证** | 五线月度折线（2021-10~2026-08 真实数据，断点插补+connectNulls） | macro_monthly |
| **三阶段预判** | 三栏压力卡（红/橙/绿） | 三阶段框架 |
| 行业评分明细 | 网格卡（五列） | 评分模型 |

### 3.3 关键交互实现

- **SSE 流式**：`fetch + ReadableStream` 逐行解析，Agent 每个工具调用实时显示（"→ search_knowledge_base 执行中…"→"✓ 完成+结果预览"）
- **图谱防抖**：初始隐藏 + 力学收敛 3.2s 后淡入（React StrictMode 兼容）
- **节点画像**：点击图谱节点 → 侧边卡展示该行业 A 矩阵消耗结构条形图/乘数/负债率口径/最新月度值
- **导出 PDF**：后端使用 ReportLab 与中文字体生成多页 PDF，完整报告和摘要均可直接下载
- **删除功能**：对话成对删除（连带报告中心记录）、报告单删/全删（三层同步）

### 3.4 视觉体系

深色金融工作台（slate-950 基调）：紧凑信息层级、蓝青强调色、风险等级五色映射与响应式移动导航；打印模式自动转白底黑字。

## 四、运行与部署

```powershell
# 一键启动（双击）
start.bat   # 自动检查依赖 → 拉起前后端 → 打开浏览器
stop.bat

# 手动
cd backend && python run.py      # :8000
cd frontend && npm run dev       # :5173
```

- 依赖版本已锁定（`requirements.txt` 精确 pin）
- LLM 可选：`.env` 配置任意 OpenAI 兼容 API；不配则规则引擎全功能运行（完全离线）
- 知识库启动时自动构建（文档变化自动重建向量）
