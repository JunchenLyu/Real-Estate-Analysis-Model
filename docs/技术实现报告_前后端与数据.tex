\begin{abstract}
本报告介绍``中国房地产产业链波动传导分析金融智能体''的技术实现，涵盖数据资产、后端架构、前端架构与部署方案四个部分。系统以大语言模型（LLM）智能体为调度核心，集成列昂惕夫（Leontief）需求侧模型与 Ghosh 供给侧模型的双投入产出引擎、四指标加权风险评分模型、混合检索知识库（RAG）与结构化案例库，输出含传导三阶段预判的结构化风险分析报告。系统具备双模式降级、数字与文字分离等可靠性设计，支持完全离线运行。经济规律的研究结论由金融方向成员另行完成，不在本报告范围内。
\end{abstract}

\subsection{双模型引擎}

系统同时实现需求侧与供给侧两类投入产出冲击模型，二者互补：

\begin{itemize}[nosep]
  \item \textbf{Leontief 需求侧}：$\Delta X = (I-A)^{-1}\Delta Y$，最终需求（投资/销售）变动向生产的传导，适用于房地产类冲击；
  \item \textbf{Ghosh 供给侧}：构造供给分配系数矩阵 $B = D^{-1}Z$（$D=\operatorname{diag}(X)$，按卖方部门总产出系数化），$\Delta X = \Delta V \cdot (I-B)^{-1}$，初始投入变动沿产业关联网络向下游传导。由于 $B = D^{-1}AD$，其与 $A$ 为相似矩阵，谱半径相同（本项目数据下 $\rho \approx 0.7303$），$I-B$ 数值稳定可逆。
\end{itemize}

\textbf{适用域说明}：Ghosh 工具用于\textbf{初始投入收缩}等数量型供给冲击情景（系统将数量型供给收缩映射为同幅度的初始投入冲击进行压力测试，两者非严格等价）；原材料\textbf{涨价}类价格/成本冲击属价格效应，不纳入该数量模型做精确量化，系统仅作定性机制提示。

\textbf{口径说明}：北京市地区投入产出表的中间使用包含跨地区调入和进口，因此 $B$ 不宜简单解释为北京市本地产出的销售分配比例，而更适合作为各行业对相关产品的中间使用暴露与产业关联强度指标。相应地，模型结果解释为供给侧投入压力沿产业链传导的情景测算，而非对北京市各行业实际产出变化的确定性预测；价格/成本冲击（如原材料涨价）属价格效应，系统不纳入该数量模型做精确量化。

两类模型各自配套专属的三阶段传导预判框架（需求侧为六案例归纳框架，供给侧为供给约束传导框架），并映射冲击幅度与行业命中情况至阶段压力指数（0--100）。

\subsection{可靠性设计}

为保障演示环境的稳定性，系统实现五层防御：

\begin{enumerate}[nosep]
  \item \textbf{双模式降级}：LLM 不可用或输出解析失败时自动切换规则引擎，全功能保持；
  \item \textbf{数字与文字分离}：所有数值由模型引擎确定性计算，LLM 仅撰写解读文本；
  \item \textbf{字段兜底}：无论 LLM 输出何种结构，影响矩阵、评分明细、三阶段、案例等字段均由 \texttt{\_enrich\_report} 确定性补齐；
  \item \textbf{检索三级降级}：MiniLM 语义 $\to$ bigram 词袋 $\to$ 纯关键词；
  \item \textbf{持久化}：报告与上传记录落 SQLite（WAL 模式），服务重启零丢失。
\end{enumerate}

\section{前端架构}

\subsection{页面结构}

前端含四个页面：智能问答（SSE 流式轨迹 + 结构化报告卡 + 对话管理）、风险仪表盘（九个可视化模块）、数据上传（拖拽解析 + 统计画像 + 文件管理）、报告中心（Markdown 渲染 + PDF 导出 + 删除）。

\subsection{仪表盘可视化模块}

风险仪表盘是系统的数据洞察中枢，由九个模块组成，覆盖``评分—影响—传导—验证—画像''五个分析层次。各模块随每次智能问答的完成自动刷新（8 秒轮询），并与最近一次分析结果保持同步。

\subsubsection{综合风险评分仪表盘}

以 ECharts Gauge 组件呈现 0--100 的综合风险评分，指针配色随风险等级五档映射（低/关注/中/高/极高分别对应绿/黄/橙/红/深红），并叠加发光阴影效果强化视觉警示。评分为行业评分的加权聚合（均值 60\% + 前三高行业均值 40\%），突出尾部风险的主导作用。

\subsubsection{行业影响条形图}

展示冲击情景下各行业产出变动百分比，负值红色、正值绿色。图表标题动态标注本次分析所用的模型类型：\textbf{Leontief 需求侧模型}（蓝色徽章，``最终需求冲击''）或 \textbf{Ghosh 供给侧模型}（琥珀色徽章，``供给约束型冲击''），使用户对分析口径一目了然。

\subsubsection{产业链传导图谱}

基于直接消耗系数矩阵构建力导向图（Force-Directed Graph），是系统的核心可视化资产：

\begin{itemize}[nosep]
  \item \textbf{节点}：13 个行业部门，节点直径映射受冲击幅度（30--75px），冲击源（房地产/建筑业）与产业链部门分色渐变（蓝色系/青色系）；
  \item \textbf{连线}：直接消耗系数 $\geq 0.03$ 的部门间供给关系（约 55 条），线宽隐含关联强度；
  \item \textbf{交互}：悬停高亮相邻连线（emphasis: adjacency）；\textbf{点击任意节点弹出行业画像侧边卡}——展示该行业的影响力乘数、基准总产出、上游消耗结构条形图（$A$ 矩阵列 Top6）、资产负债率及其统计口径、最新月度指标，以及当前风险评分；
  \item \textbf{稳定性}：初始隐藏 + 力学收敛（约 3.2 秒）后淡入的防抖策略，配合节点碰撞半径（collide）避免标签重叠，画布绝对定位铺满卡片保证图例与模块底边对齐。
\end{itemize}

\subsubsection{历史对比折线图}

2015--2024 年房地产投资增速与 GDP 增速的年度双线对比，标注零轴参考线，直观呈现 2022 年起房地产投资连续负增长与 GDP 韧性的分化。

\subsubsection{传导验证图（真实月度数据）}

九条 2021 年 10 月至 2026 年 8 月的月度同比序列同图呈现：新开工面积、商品房销售面积（地产端先行/同步指标）、水泥产量、平板玻璃产量、粗钢产量（上游传导验证）、PPI（价格维度），以粗线突出新开工指标。该图以真实统计数据直接验证``地产下行 $\to$ 上游产量收缩''的传导时序，是模型结论的实证支撑。针对统计发布制度造成的缺失月份（1--2 月合并发布、12 月无单月值）做邻月插补，并启用 \texttt{connectNulls} 保证折线连续。

\subsubsection{传导三阶段预判卡}

三栏布局呈现阶段化传导预判：每栏含阶段名称、压力指数（0--100，红/橙/绿三档配色进度条）、时间窗、传导机制、命中行业标签组，以及可展开的验证指标与案例证据。需求侧冲击展示六案例归纳框架（直接冲击期 0--6 月 $\to$ 深度传导期 6--24 月 $\to$ 存量重构期 24 月+），供给侧冲击展示供给约束传导框架（供给冲击期 $\to$ 成本传导期 $\to$ 替代重构期）。

\subsubsection{历史案例对标卡}

展示本次分析命中的结构化案例（9 个案例库中按触发路径加权检索），每条含案例名称、量化峰值影响（如``恒大总负债 2.44 万亿、应付票据 6669 亿''）与经验启示。

\subsubsection{建议关注指标卡与行业评分明细}

前者以标签墙形式呈现 Agent 输出的监测指标清单（领先/同步/滞后分层）；后者以网格卡片展示各受影响行业的风险评分及其四项分指标（收入 30\%、债务 30\%、现金流 20\%、市场需求 20\%）进度条。

\subsection{关键技术实现}

\begin{itemize}[nosep]
  \item \textbf{SSE 流式}：\texttt{fetch + ReadableStream} 逐行解析，工具调用实时显示``执行中 $\to$ 完成''状态；
  \item \textbf{图谱防抖}：初始隐藏、力学收敛后淡入（React StrictMode 兼容），节点碰撞半径防止标签重叠；
  \item \textbf{节点画像}：点击图谱节点展示该行业消耗结构、乘数、负债率口径与最新月度数据；
  \item \textbf{PDF 导出}：打印样式解除滚动容器限制，长报告正确分页；
  \item \textbf{数据断点处理}：对统计发布制度造成的缺失月份做邻月插补，并启用 \texttt{connectNulls} 保证折线连续。
\end{itemize}
