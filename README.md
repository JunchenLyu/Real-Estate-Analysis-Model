## 快速开始

### 方式一：一键启动（推荐）

```
双击 start.bat → 浏览器自动打开 http://localhost:5173
```

自动完成：依赖检查与安装（首次）→ 拉起后端(:8000) + 前端(:5173) → 打开浏览器。停止服务双击 `stop.bat`。

### 方式二：手动启动

```powershell
# 后端
cd backend
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
python run.py            # http://localhost:8000 （接口文档 /docs）

# 前端（新终端）
cd frontend
npm install && npm run dev   # http://localhost:5173
```

### 可选：接入大模型 API

系统默认以**规则引擎**运行（零配置、完全离线可用）。配置任意 OpenAI 兼容 API 后切换为真实 LLM Function Calling：

```ini
# 复制 backend/.env.example 为 .env，填入：
LLM_API_KEY=你的key
LLM_BASE_URL=https://api.deepseek.com/v1     # 或智谱等任意兼容端点
LLM_MODEL=deepseek-chat
```

> LLM 调用失败自动降级规则引擎——比赛现场永不翻车。

## 系统架构

```
┌───────────────────────── Frontend (React + Vite + Tailwind + ECharts) ─────────────────────────┐
│  智能问答(SSE流式轨迹+结构化报告) │ 风险仪表盘(评分/图谱/传导/画像) │ 数据上传 │ 报告中心(MD/PDF) │
└────────────────────────────────────────────┬───────────────────────────────────────────────────┘
                                             │ REST + SSE
┌────────────────────────────────────────────▼───────────────────────────────────────────────────┐
│                          Backend (Python FastAPI + SQLite 持久化)                                │
│  Agent Core: LLM Function Calling 循环 / 规则引擎降级（生成器流式）                              │
│  ├── search_knowledge_base   → Chroma 向量库（8700+切片，混合检索：MiniLM语义+bigram+RRF）      │
│  ├── analyze_industry_chain  → 列昂惕夫模型 X=(I-A)⁻¹Y（北京2023真实表，13部门）                │
│  ├── compute_risk_score      → 多指标加权风险评分（真实行业负债率口径）                          │
│  ├── retrieve_similar_cases  → 历史风险案例库（结构化检索）                                       │
│  ├── analyze_uploaded_data   → pandas 统计分析 + 风险指标识别                                    │
│  └── /api/industry/{name}    → 节点画像（消耗结构/乘数/月度数据）                                │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 核心功能

| 模块 | 功能 | 技术点 |
|---|---|---|
| **智能问答** | 输入冲击情景 → 结构化风险报告（摘要/风险等级/影响产业/传导路径/模型依据/数据依据/关注指标） | LLM 工具调用；**核心结构化量化字段由确定性模型引擎计算并强制覆盖，降低生成式数字幻觉影响** |
| **流式轨迹** | 实时显示 Agent 每一步工具调用（"→ 执行中" → "✓ 完成+结果"） | SSE + 生成器 |
| **双模型引擎** | 需求侧 Leontief `X=(I-A)⁻¹Y` + 供给侧标准 Ghosh `ΔX=ΔV·(I-B)⁻¹`（B=D⁻¹Z 供给分配系数），Agent 按问题语义自动路由（"房地产投资下降" vs "钢铁初始投入收缩"） | 双投入产出模型 |
| **传导三阶段** | 冲击分析自动输出阶段化预判：需求侧六案例框架 / 供给侧传导框架，压力指数 0-100 | 自建分析框架 |
| **风险仪表盘** | 评分仪表盘 / 行业影响（双模型徽章）/ **产业链图谱**（力导向+节点画像）/ 历史对比 / 传导验证（真实月度）/ 三阶段卡 / 案例对标 | ECharts（评分为情景压力比较口径，详见技术报告） |
| **节点画像** | 点击图谱节点：A 矩阵消耗结构、乘数、负债率（含口径）、最新月度数据 | 交互式探索 |
| **数据上传** | CSV/Excel 拖拽上传 → 自动统计画像 + 风险指标识别 + 实时评分；历史可回看/下载原文 | pandas |
| **报告中心** | 六章结构 Markdown 持久化 → 下载 .md / 导出 PDF（正确分页）；单删/全删 | 模板化生成 |
| **持久化** | 报告/上传记录 SQLite 落库，**重启零丢失** | sqlite3 WAL |

## 与普通 AI 聊天的本质区别

| | 普通聊天机器人 | 本系统 |
|---|---|---|
| "下降15%影响多大" | 编一个合理的数字 | 列昂惕夫逆矩阵计算（北京2023真实表），**核心结构化量化字段由确定性引擎强制覆盖** |
| 引用来源 | 无 | 60+ 篇文献/官方数据，可溯源 |
| 结论可复现 | 每次不同 | 模型确定性输出，可审计 |
| 输出 | 一段文字 | 评分+矩阵+图谱+报告，全链路 |

## 数据与模型口径

- **A 矩阵**：北京市 2023 年投入产出表（42 部门基本表，当年生产者价格），聚合为 13 部门，提取脚本 `testdata/extract_io_2023.py` 全程可复现
- **行业负债率**：房地产=国资委全行业口径；建筑/钢铁/建材/家电=申万三级行业近 5 年均值
- **月度传导数据**：Wind/国家统计局，2021-10 ~ 2026-08（销售/投资/新开工/水泥/粗钢/玻璃/PPI）
- **知识库**：60+ 文献（含券商深度研报）+ 北京投入产出表系列 + 政策文件，切片 8700+
- **历史案例**：9 个结构化案例（国际/地区 3：日本1990、美国2008、海南1992 + 房企 6：恒大/融创/碧桂园/金科/世茂/阳光城）

## 常见问题 FAQ

**Q：不配置 LLM API 能用吗？**
能。规则引擎模式完整可用（模型测算/知识库/报告/Dashboard 全功能），LLM 仅增强摘要与推理。

**Q：上传的数据会出网吗？**
文件与明细只存本地 `backend/uploads/`。配置了外部 LLM 时，仅统计摘要参与推理。

**Q：报告/上传记录重启会丢吗？**
不会。SQLite 持久化，启动自动恢复。

**Q：向量库如何构建？**
启动时自动扫描 `backend/app/knowledge/documents/*.md` 切片入库；MiniLM 语义嵌入本地运行（模型已缓存时），缺失自动降级 bigram。
